# 📑 Frappe AI Document Scanner

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-v14%20%7C%20v15-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An intelligent OCR & Vision parsing agent that extracts data from vendor PDF/image bills and automatically converts them into draft **Purchase Invoice** DocTypes in ERPNext.

---

## ⚡ Features
- 🔍 Automatic extraction of Supplier GSTIN, Tax ID, Invoice Number, and Bill Date.
- 📦 Tabular parsing of line items, quantities, unit rates, and totals.
- 🔄 Seamless payload generator for ERPNext REST API.
- 🧪 Pytest test suite included.
